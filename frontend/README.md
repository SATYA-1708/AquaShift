# AquaShift Frontend

React/TypeScript and Vite user interface for AquaShift. It includes map and chart dependencies used to present agricultural, geospatial, and scenario data from the backend.

From this directory, run `npm ci`, then `npm run dev`. Use `npm run build` to build and `npm run lint` for linting. Configure the API connection as expected by the frontend source. The companion API and full-stack Docker setup are documented in the repository-level [`README`](../README.md).
